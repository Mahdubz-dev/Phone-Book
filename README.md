# 📱 Phone Book

A simple **command-line Phone Book application built with Python**.

This project was created as a portfolio project to practice Python fundamentals, data structures, functions, loops, input validation, and basic clean code principles.

## ✨ Features

* ➕ Add a new contact
* 📞 Add multiple phone numbers to an existing contact
* 🔎 Search for a contact by name
* 🗑️ Remove a contact
* 👥 Count the number of contacts
* 📋 Show all contacts and their phone numbers
* 🚪 Exit the application
* ⚠️ Input validation for phone numbers
* 🔄 Limited attempts for invalid Yes/No inputs

## ▶️ How to Run

Make sure Python is installed on your system.

Clone the repository:

```bash
git clone https://github.com/Mahdubz-dev/Phone-Book.git
```

Navigate to the project directory:

```bash
cd Phone-Book
```

Run the original version:

```bash
python phone_book.py
```

Or run the cleaner version:

```bash
python phone_book_v2.py
```
